# SpeakUp

SpeakUp é uma plataforma desenvolvida para facilitar o registro e acompanhamento de denúncias e problemas urbanos.

O sistema foi idealizado no contexto do Projeto Integrador do curso de Engenharia de Software da UniEVANGÉLICA, com foco em acessibilidade, organização de informações e melhoria da comunicação entre cidadãos e órgãos responsáveis.

## Funcionalidades

- Registro de denúncias
- Acompanhamento de status
- Dashboard administrativo
- Histórico de ocorrências
- Sistema de notificações
- Filtros e organização de dados
- Interface responsiva

## Tecnologias Utilizadas

- HTML
- CSS
- JavaScript
- TypeScript
- React
- Vite
- TailwindCSS
- shadcn/ui

## Objetivo

Centralizar informações sobre problemas urbanos em uma plataforma intuitiva, permitindo maior transparência, organização e acompanhamento das ocorrências registradas pela população.
